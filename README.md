## درباره‌ی پروژه

«یکی از یک زندگی» جایی است برای ثبت و خواندن **درس‌هایی که زندگی به آدم‌ها داده است**. هر کاربر در هر لحظه فقط **یک درس فعال** دارد — چکیده‌ی مهم‌ترین چیزی که تا امروز آموخته. وقتی درس تازه‌ای می‌نویسد، درس قبلی بایگانی می‌شود و سیر تحول نگاهِ او در طول زمان قابل دیدن است.

برخلاف شبکه‌های اجتماعی معمول، این برنامه عمداً **محدود و آرام** طراحی شده است: فید بی‌پایان ندارد، لایک ندارد، و نگه‌داشتن یا تأیید یک درس سهمیه‌ی محدودی دارد تا هر انتخاب معنا داشته باشد.

رابط کاربری **فارسی و راست‌به‌چپ** است و از حالت روشن و تاریک پشتیبانی می‌کند.

## امکانات

| بخش | توضیح |
|---|---|
| **یک درس (One)** | هر بار یک درس تصادفی از یک انسانِ دیگر — بدون نمایش درسِ خودتان. |
| **پرسه (Wander)** | کشف تصادفی و متنوع، با سقف **۷ درس در هر نشست**. |
| **کاوش (Explore)** | جست‌وجو و فیلتر بر اساس **موضوع**، **گروه سنی** و **کشور**؛ به‌همراه مجموعه‌های گزینش‌شده مثل «عشق در سه نسل» و «دو زندگی، دو درس». |
| **درس‌های پیشین** | بایگانی درس‌های جایگزین‌شده، کنار درس فعلی همان نویسنده — برای دیدن اینکه نگاه آدم‌ها چطور تغییر می‌کند. |
| **سفر من (Journey)** | آرشیو خصوصی هر کاربر: درس‌های خودش، درس‌های نگه‌داشته و یادداشت‌های تأملی. |
| **نگه‌داشتن (Keep)** | ذخیره‌ی یک درس — حداکثر **۳ بار در ماه**. |
| **«به این نیاز داشتم» (Needed)** | نشان دادن اینکه یک درس به‌موقع به دستتان رسید — حداکثر **۱ بار در هفته**. |
| **تأمل (Reflect)** | نوشتن یادداشت شخصی و خصوصی روی هر درس. |
| **کارت اشتراک** | ساخت کارت قابل‌اشتراک برای هر درس، با لینک مستقیم (`#lesson-<id>`). |
| **حالت ناشناس** | انتشار درس بدون نمایش نام، فقط با سن و مکان. |
| **گزارش و نظارت** | کاربران می‌توانند درس نامناسب را گزارش دهند؛ مدیر آرشیو آن را پنهان، بازگردانی یا رد می‌کند. |

**۱۴ موضوع:** عشق، فقدان و سوگ، خانواده، دوستی، شکست و آزمون، کار و رسالت، ثروت و مادیات، زمان و کهنسالی، شجاعت و جسارت، تغییر و گذار، آزادی و رهایی، افسوس و حسرت، رشد و خرد، معنای زندگی.

هر درس حداکثر **۷۰۰ نویسه** است و می‌تواند یک توضیح اختیاری داشته باشد: «چه چیزی این را به شما آموخت؟»

## فناوری‌ها

- **فرانت‌اند:** React 19، TypeScript، Tailwind CSS 4، Motion (انیمیشن)، Lucide (آیکون)
- **بک‌اند:** Express 4 روی Node.js، اجرا با `tsx` در توسعه و باندل‌شده با `esbuild` در تولید
- **پایگاه داده:** یک فایل JSON ساده (`data/database.json`) که هنگام اولین اجرا با ۲۷ درس نمونه پر می‌شود
- **ابزار ساخت:** Vite 6 (در حالت توسعه به‌صورت middleware داخل همان سرور Express اجرا می‌شود)

**پیش‌نیاز:** Node.js نسخه‌ی ۱۸ یا بالاتر

سپس به آدرس <a href="http://localhost:3000">http://localhost:3000</a> بروید. سرور و رابط کاربری هر دو روی پورت **۳۰۰۰** اجرا می‌شوند.

### ورود

برای راحتیِ کاوش، ورود فعلاً حالت دمو دارد: با وارد کردن **هر ایمیلی** وارد می‌شوید و اگر حسابی با آن ایمیل نباشد، خودکار ساخته می‌شود. ایمیل‌هایی که کلمه‌ی `admin` در آن‌ها باشد (مثلاً `admin@onefromalife.com`) دسترسی **مدیر آرشیو** و صفحه‌ی نظارت را می‌گیرند.

### اسکریپت‌ها

| دستور | کار |
|---|---|
| `npm run dev` | اجرای سرور توسعه با Vite و بارگذاری مجدد خودکار |
| `npm run build` | ساخت فرانت‌اند در `dist/` و باندل سرور در `dist/server.cjs` |
| `npm start` | اجرای نسخه‌ی ساخته‌شده |
| `npm run lint` | بررسی نوع‌ها با TypeScript |
| `npm run clean` | پاک کردن خروجی ساخت |

### اجرای نسخه‌ی تولید

### متغیرهای محیطی

فایل `.env.example` را به `.env` کپی کنید. در کد فعلی هیچ‌کدام از این متغیرها برای اجرا لازم نیستند؛ این فایل از قالب اولیه‌ی Google AI Studio باقی مانده است.

| متغیر | توضیح |
|---|---|
| `GEMINI_API_KEY` | کلید Gemini — در نسخه‌ی فعلی استفاده نمی‌شود |
| `APP_URL` | آدرس عمومی برنامه — در نسخه‌ی فعلی استفاده نمی‌شود |
| `DISABLE_HMR` | با مقدار `true` بارگذاری مجدد خودکار Vite خاموش می‌شود |

## API

همه‌ی مسیرها زیر `/api` هستند. مسیرهای نیازمند ورود، هدر `Authorization: Bearer <token>` می‌خواهند.

| متد | مسیر | ورود | کار |
|---|---|:---:|---|
| `POST` | `/auth/signup` | — | ثبت‌نام |
| `POST` | `/auth/login` | — | ورود (حالت دمو) |
| `GET` | `/auth/me` | اختیاری | کاربر فعلی، درس فعال و سهمیه |
| `POST` | `/auth/update-profile` | ✓ | ویرایش نام، سن، مکان، حالت ناشناس |
| `GET` | `/lessons/one` | اختیاری | یک درس تصادفی (`?exclude=<id>`) |
| `GET` | `/lessons/wander` | اختیاری | تا ۷ درس تصادفی |
| `GET` | `/lessons/explore` | اختیاری | فیلتر با `topic`، `ageGroup`، `country`، `search` |
| `GET` | `/lessons/curated-collections` | — | مجموعه‌های گزینش‌شده |
| `GET` | `/lessons/previous` | اختیاری | درس‌های بایگانی‌شده و تحول نویسنده |
| `GET` | `/lessons/:id` | اختیاری | یک درس مشخص |
| `POST` | `/lessons` | ✓ | انتشار درس تازه (درس قبلی بایگانی می‌شود) |
| `POST` | `/lessons/:id/needed` | ✓ | «به این نیاز داشتم» |
| `GET` | `/user/journey` | ✓ | تاریخچه‌ی درس‌های خود کاربر |
| `GET` / `POST` | `/user/keeps` | ✓ | فهرست و نگه‌داشتن/رها کردن درس |
| `GET` / `POST` | `/user/reflections` | ✓ | فهرست و ثبت یادداشت تأملی |
| `POST` | `/reports` | ✓ | گزارش یک درس |
| `GET` | `/admin/moderation` | مدیر | فهرست گزارش‌ها |
| `POST` | `/admin/moderation/action` | مدیر | `hide` / `restore` / `dismiss` |

## پیش از استقرار عمومی

این نسخه یک نمونه‌ی اولیه است و برای کاوش و نمایش ساخته شده. پیش از انتشار عمومی، این موارد باید درست شوند:

- **احراز هویت:** هنگام ورود رمز عبور بررسی نمی‌شود و توکن همان شناسه‌ی کاربر است. رمزها هم بدون هش ذخیره می‌شوند. باید رمز را با `bcrypt` یا `argon2` هش کرد و از توکن امن (مثلاً JWT یا session) استفاده کرد.
- **دسترسی مدیر:** هر ایمیلی که `admin` در آن باشد مدیر می‌شود. نقش مدیر باید فقط به‌صورت دستی یا از طریق متغیر محیطی تعیین شود.
- **پایگاه داده:** فایل JSON برای چند کاربر هم‌زمان مناسب نیست. برای تولید، SQLite یا PostgreSQL پیشنهاد می‌شود.
- **داده‌ی آزمایشی:** فایل `data/database.json` در مخزن commit شده و حساب‌های آزمایشی دارد. بهتر است آن را به `.gitignore` اضافه کنید تا با اولین اجرا از داده‌ی نمونه ساخته شود.
